# SQL Queries

Repository created to practice and review SQL concepts using the AdventureWorks database.

## About

This repository contains SQL queries developed as part of my studies in SQL and data analysis.

The exercises cover topics such as:

- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate functions
- DISTINCT
- Subqueries
- Data analysis
- Fact and dimension tables

## Database

The queries in this repository are primarily based on the AdventureWorks sample database.

## Objective

The goal of this repository is to consolidate my SQL knowledge through practical exercises and demonstrate my ability to query, analyze, and extract information from relational databases.

The repository will be continuously updated as I progress in my studies.
